# 秋葉原ミニシティ：街の骨格 試作1号

本番プロジェクトのローカル確認用。`node tools/preview-server.cjs`（または `npm run preview`）で起動し、表示されたURLを開く。4317から空きポートを選ぶため、既存サーバーを停止しない。外部公開は行わず127.0.0.1だけで待ち受ける。Three.jsは既存テストと同じ固定バージョン0.180.0をCDNから読み込むため、初回表示にはネット接続が必要。

矢印キーで画面基準の4方向移動。同じキーを250ms以内に2回押し、2回目を保持するとダッシュ。通常3.0、ダッシュ4.8ゲーム単位/秒。`src/player/walking.js` はプロジェクト内の既存テストから無変更でコピー。モデルも既存の茶タヌキv2を直接使用し、GLB内の確認用床と照明だけ非表示。テストフォルダと素材原本は変更しない。

配置は指定された「秋葉原ミニシティ_マップ設計シート.xlsx」の「マップ編集」B6:O20のセル背景色を `src/map/layout.js` に転記。資料内の古い方角・寸法の説明は採用せず、実配置と今回の依頼を優先。B6が左上、Xは右、Zは下。1セル2.0、全体28×30。高架で隠れる道路はExcelの周回路に合わせて9行目・15行目のH:I、16行目のC・Nで連続させる。

仮設定は `src/map/world.js` に集約。高架・駅の上面4.0、厚さ0.25、下面3.75。高架と駅は常時不透明度0.30で表示し、下のタヌキを視認できる簡易表現。柱や駅舎・電車は未配置。歩道幅0.18、段差0.014で道路セル内に収める。建物予定区画はExcelの色に対応した地面だけ。F18は広場色の空き地。

陸上は全区画を歩行可能。海と外周のみ中心位置を境界の0.45内側に制限する。範囲はX=-13.55〜13.55、Z=-12.55〜14.55。砂浜は歩けるが海には入れない。`src/camera.js` は左手前から俯角約35度の正投影、表示高18、位置だけ追従する。

確認ページ `/tools/verify.html` は4方向の速度、ダブルタップ、時間切れ、自動リピート、キー解放、方向優先、フォーカス喪失、道路接続、高架層、陸196セルへの到達性、移動制限と追従を検証する。ゲーム本体には検証操作を組み込まない。
