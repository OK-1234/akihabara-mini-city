# 秋葉原ミニシティ：街の骨格 試作2号

`node tools/preview-server.cjs` または `npm run preview` で確認用サーバーを起動。表示されたURLを開く。4317から空きポートを選び、既存サーバーは停止しない。127.0.0.1のみで待ち受ける。Three.js 0.180.0はCDNから読み込むためネット接続が必要。

## 仮設定

- タヌキの表示スケール0.45。GLB・形状・色は未変更。実モデルの幅約0.878、高さ約1.451。
- 道路幅4.0（試作1号の2倍）。タヌキの横幅約4.6体分。歩道各0.45、車道3.1。
- 高架幅は縦横とも4.0。駅も同一層で上面2.6、下面2.35。常時半透明表示を維持。
- 駅裏は道路との間に奥行3.0を追加。広場の18行目の奥行は2.0から4.0へ拡大。F18は空き地。
- 砂浜の奥行3.0。海は元の海セルの上端から北へ80、左右各80延長。
- カメラは左手前から俯角約35度を維持し、位置のみ追従。正投影の表示高9.0、横幅9.0×画面アスペクト比。
- 移動制限は海際・外周の0.4内側。陸上区画は歩行可能。

配置の正本は docs/reference/秋葉原ミニシティ_マップ設計シート.xlsx の「マップ編集」B6:O20。背景色は試作1号と一致することを再確認済み。最新依頼に従い位置関係を維持し、道路列・行、駅周辺、広場、砂浜の寸法を拡張。寸法は src/map/world.js の列幅・行奥行・定数で管理する。

## 操作

今回の具体例に合わせ、↑は画面右上、↓は左下、←は左上、→は右下。カメラの方向ベクトルから変換し街路の2軸に沿って移動する。同時押しは最後の方向を優先。

通常3.0、ダッシュ4.8ゲーム単位/秒を維持。縮小で実速度が遅くならないよう補正。同じキーを250ms以内に2回押し、2回目を保持してダッシュ開始。キーを押し継いでいる間は方向転換後も継続し、全キーを離すと解除。次の押下は通常歩行から。自動リピートは数えず、フォーカス喪失時も解除。歩行周期・手足の振りを維持。
