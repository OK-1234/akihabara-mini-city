# タヌキ v2 最小歩行テスト

このフォルダでPowerShellを開き、次を実行します。

```powershell
npx --yes serve . -l 8000
```

ブラウザーで http://localhost:8000/ を開いてください。Three.jsの読み込みにはインターネット接続が必要です。HTMLのダブルクリックでは動作しません。

矢印キーを押している間だけ、画面の上下左右へ歩きます。同時押しは最後に押した方向を優先します。タヌキは進行方向を向き、左右の手足を交互に振り、体が少し上下します。キーを離すと停止して手足と高さが元に戻ります。別ウィンドウやタブへ移った場合も入力を解除します。

前回の表示テストは残し、コピーに歩行を追加しました。カメラ・倍率・色味・ライト・床・GLBは前回と同じです。v1は従来どおり比較条件の採寸専用で、表示はv2のみです。

頭身・歩き方のかわいさ・見やすさを確認してください。固定カメラなので歩き続けると画面外へ出ます。反対方向のキーで戻るか、再読み込みで初期位置に戻れます。

クリック移動、Eキー、街、車、UI、カメラ操作、追従、障害物判定はありません。GAME_SPEC.mdでの正式採用はまだ行っていません。

元の初期速度を1.0とした移動速度は通常2.5、ダッシュ4.0です（初期実速度1.2 → 通常3.0、ダッシュ4.8）。同じ矢印キーを250ミリ秒以内に2回押すと、2回目を押している間だけダッシュします。そのキーを離すと解除します。手足の振りと体の上下動は従来どおりです。
