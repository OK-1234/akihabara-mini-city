## 2. ゲームの目的・世界観【確定】

- 明るくかわいいCozy Blockの雰囲気を基準に、秋葉原の特徴を取り入れた、コンパクトな3Dの街を作る。
- タヌキで街を歩き、街の景色や小さな発見を楽しみ、最終的に就労移行支援の建物へ向かう。
- 実際の秋葉原の道路・建物を精密に再現することは目的にしない。駅、高架、電車、建物の密集感、主要ランドマークの位置関係で街を表す。
- オタク・メイド・PCショップ表現を前面に出さない。独立した電気街エリアは作らない方針。
- UDX・ヨドバシは設計上の呼称。実物の文字・ロゴを再現することは要件にしない。店名や細かい看板文字は不要。
- 発表時のPC操作を優先する。スマホ対応は後回し。

根拠：[会話] 世界観、道路の単純化、電気街不要、PC優先のやり取り。

## 3. タヌキ【確定】

### 3.1 採用モデルと見た目

- ゲームで読み込む基準モデルは **`tanuki_brown_v2.glb`**。
- 茶タヌキv2の現在の造形・頭身・色を維持する。文章から別のタヌキを再設計しない。
- **現在のゲーム内スケール0.45（試作2〜3号）を維持する。** 車・電車の縮尺はこのタヌキを基準に合わせる。【縮尺校正確定】
- 二足直立、短い手足、耳と尻尾、頭の緑の葉っぱ、黒い画面のような顔と青系の縦目というデザインを引き継ぐ。
- 少し角ばった形に丸みを残す方向。リアルな毛並みや四足歩行は採用しない。
- 造形は原則固定。街に置いて明らかな縮尺問題が出た場合のみ、再調整を検討する。
- 白＋黒の「しろたぬき」は、茶タヌキと同形状・同サイズ・同じ動きの配色違いとして追加予定。葉っぱは緑。選択できる方針はあるが、初期制作は茶タヌキを先にする。
- 白タヌキのファイル名や選択画面の方式は未確定。

### 3.2 通常歩行とダッシュ

**すべての速度倍率は「元の初期速度＝1.0」を基準とする。** ダッシュ4.0倍は、採用済み通常歩行速度の4倍という意味ではない。

| 項目 | 採用仕様 |
| --- | --- |
| 通常歩行 | 元の初期速度の **2.5倍** |
| ダッシュ | 元の初期速度の **4.0倍** |
| 発動条件 | **同じ矢印キーを250ms以内に2回押し、2回目を保持するとダッシュ開始** |
| 通常入力 | 試作2〜3号の画面基準操作を採用。↑＝画面右上、↓＝左下、←＝左上、→＝右下 |
| 同時押し | 最後に押した方向を優先。斜め移動は追加しない |
| ダッシュ中の方向転換 | 移動キーの入力が継続している間は、別方向へ切り替えてもダッシュを継続。再度のダブルタップは不要 |
| キー解放 | すべての移動キーを離すと停止し、ダッシュ解除。次に移動を開始するときは通常歩行から |
| 自動リピート | 押しっぱなしによるキーの自動リピートをダブルタップに数えない |
| フォーカス喪失 | 別ウィンドウ・タブへの切替時は入力とダッシュ状態を解除 |

引き継ぎ資料に記録された歩行テストのコード上の値は、初期実速度 **1.2**、通常 **3.0**、ダッシュ **4.8**。これらは当該テストの値であり、m/sなどの現実単位は未確認。

### 3.3 モーション

- 気に入っている**トコトコ歩行モーションを維持**する。
- 手足の交互の振り、体の小さな上下動、進行方向への向き変更は既存のまま。
- ダッシュ速度と手足の動きを厳密同期させない。**ダッシュ時は多少床を滑る感じを許容**する。
- しゃがみ・待機モーションは不要。スタート／ゴールの手振りは別の演出として追加する。

根拠：[今回指定]、[引継ぎ] 4〜7節、[会話] タヌキ造形固定・白タヌキ・不要モーションの整理、[縮尺校正確定] 現在のタヌキスケール・画面基準操作・方向転換中のダッシュ継続。

## 5. カメラ

### 確定

- **左斜め下側から見下ろす、固定寄りアイソメトリック**を基本とする。
- 徒歩と車で基本の見方を共通にする。
- 基本の角度・倍率を維持し、街の中でタヌキを見て操作できることを重視する。
- 操作対象が移動すると世界の表示範囲がスクロールする、初代FF7に近い見え方を目指す。
- **試作2〜3号の現在のカメラ角度・追従・探索感を維持する。** 周囲を歩くと少し先の区画が見えてくる表示範囲を基準とし、マップ全体を見せるためにカメラを引かない。【縮尺校正確定】
- 遮る建物は透過させる方針。カメラが急に上空へ移動することで視界を確保する旧テストの挙動は基準にしない。

### 未確定・後回し

- カメラは試作2〜3号の現在の設定・見え方を基準とする。今後の本番素材導入に伴う追加調整の具体値は未確定であり、今回の採用を全体表示への変更理由にしない。
- 遮蔽物の透過率、透過が続いた場合の消え方、復帰条件は未確定。
- 小街区密度テストでは透過処理を追加せず、一時的な遮蔽も確認対象とする。将来は、長時間タヌキと進行方向が分からなくなる場合に限定して透過する方式を検討する。【密度テストのユーザー指定】
- 観光用の見上げカメラ、運転者視点、全体視点などの切替は後回し。

初版時点の単体歩行テストは固定カメラで、歩き続けると画面外へ出ると報告されていた。現在は試作2〜3号の追従を採用する。遮蔽物判定の本番実装が完了したという意味ではない。単体表示比較で使った「画面高さの約1/4〜1/3」は、街全体の最終カメラ仕様ではない。

根拠：[今回指定]、[会話] カメラ方針、[引継ぎ] 6・9節。

## 6. スタートとゴール【確定・追加予定】

### スタート

**広場にいるタヌキがカメラに手を振る → 操作開始。**

駅から来たタヌキという背景を引き継ぐ。以前の「電車到着→駅出口から歩いて出る」という前段演出は追加候補であり、今回確定した広場でのスタートに必須として付け足さない。

### ゴール

**就労移行支援の建物入口へ近づく →「！」表示 → E → カメラに手を振る → 建物へ入る → 暗転。**

近づいただけで終了せず、Eで入館演出へ進む。建物の正式名称、入口座標、判定距離、手振りや暗転の秒数、暗転後の画面は未確定。

根拠：[今回指定]、[会話] 広場スタート・入館暗転・Eへの統一。

## 7. 車への変身と走行

### 7.1 変身の採用候補

今回の依頼で「案」として指定されたため、変身方式は採用候補として記録する。

**化けられる車へ近づく →「！」→ E → 白い煙 → 対象車に化け、その車が操作対象になる。**

- 対象車そのものを白くして、屋根に緑の葉っぱを載せる案。
- 変身後は前後に青い目を付ける方向が会話で支持されている。
- 茶タヌキ・白タヌキのどちらも、化けた後は白い車にする方針。
- 普通の乗り込みアニメーションではなく、煙で切り替える。
- 初期版は停車中の限られた車を変身対象にする案。全走行車への変身は後回し。
- Eで停車・煙・タヌキへ復帰する案。復帰位置、元の車の色や状態、その場に残す車の扱いは未確定。
- 変身可能な車の台数・配置点、判定距離、煙の実装方式・時間は未確定。

### 7.2 運転の確定方針

- 通常は**道路に沿って自動で前進**する。
- 外周道路を**反時計回り**に周回する。
- **↑長押しで加速、離すと通常速度に戻り、↓でバック**する。
- 左右のハンドル操作は入れず、カーブは道路ルートに沿って曲がる方向。
- 「自動運転ボタン」「自動運転ON/OFF」は不要。
- 他の走行車は**透過／非衝突を基本**とする。
- 追い越し用の車線変更や専用モーション、複雑な交通AIは初期実装の要件にしない。

通常速度、最高速度、加減速量、バック速度、ルートの曲がり方、透過の発動条件は未確定。タヌキの速度値を車へ流用しない。

根拠：[今回指定]、[会話] 対象車への変身案、E、通常自動前進、反時計回り、他車透過。

## 8. マップ・駅・高架・電車

### 8.1 マップの正本【確定】

配置の正本は、会話で共有された **`秋葉原ミニシティ_マップ設計シート.xlsx`**。セル配置をゲーム用の配置へ変換する。旧画像・旧図・会話中の配置説明と食い違う場合、最新Excelのセル配置を優先する。

今回、このExcel本体のセル内容は再読していない。したがって、正確なセル番地・座標・マス数・寸法は本書に転記しない。会話内に引用されていた別の旧引き継ぎ資料の全文も今回の確認対象には含めていない。

### 8.2 会話で確定した構成方針

- 道路は単純な外周の周回路を基本とし、道路網をむやみに増やさない。
- 道路は **「歩道｜2車線｜歩道」** の構造を基本とする。【縮尺校正確定】
- 碁盤の目は建物や区画の配置を共有するために使う。
- 中央の縦高架と横高架が交差し、その交差位置に駅を置く。駅と高架・線路をつなぐ。
- 高架下を徒歩・車で通れるようにする。高架下を暗くしない。地面をくぼませる旧案は採用しない。
- **高架幅は3.0ゲーム単位を本番基準として確定し、縦高架・横高架とも基本幅を3.0で統一する。**【高架・電車確定】
- 高架中央には **`assets/railway/track-detailed.glb`** を本番基準の線路素材として配置する。【高架・電車確定】
- 線路の左右にはタヌキが歩ける細い歩行余白を残す。広い歩道ではなく、電車の横をタヌキが通れる程度の細い通路として扱う。【高架・電車確定】
- 高架の左右には基本的に側壁を設ける。階段など地上との接続が必要な指定箇所では側壁を開口できる。【高架・電車確定】
- UDX風、ヨドバシ風、就労移行支援の建物、駅、広場を配置対象にする。
- UDXは正方形に近い占有面積感、ヨドバシは区画の端から端に届く縦長の占有形状という希望を引き継ぐ。
- ヨドバシ風は建物群ボリューム試作のサイズ感を当面維持する。将来の本番化では、角の丸み、低層部と上層部のシルエット差、簡単な壁面の凹凸で圧迫感を軽減する方向を検討する。外周が主な走行・歩行ルートのため、道路から大きく後退させることを主解決策にしない。具体デザインは未確定で、1区画街歩き試作では作り込まない。【1区画街歩き試作のユーザー指定】
- 就労移行支援はUDXと同じ左側区画の左上側という方針。最終位置はExcelに従う。
- 噴水は広場左側に置き、カメラの邪魔になりにくくする方針。中央へ移す・削除する旧提案は戻さない。
- 駅前広場には、将来の **噴水・ベンチ・NPC・タヌキの通行が共存できる余白** を持たせる。この空間方針の採用は、各オブジェクトの実装完了や制作順の変更を意味しない。【縮尺校正確定】
- マップ端に砂浜と海をつなげる。四方を海で囲む島にはしない。タヌキが砂浜まで行ける方向。
- **砂浜は現在の奥行きを持つエリアとしての方向性を採用し、アクセスは2か所とする。** 海は果てが簡単に見えない現在の見せ方を維持する。【縮尺校正確定】

広場の位置は途中で変更されているため、旧会話の「駅の左上」などを最終座標として固定しない。海岸の方向・境界も最新Excelに従う。

### 8.3 電車の本番基準・駅と編成

- 本番基準の電車素材は **`assets/trains/train-electric-square-a.glb`** とする。【高架・電車確定】
- **uniform scaleは0.95を基準として確定する。** XYZすべてに同じ倍率を適用し、モデル本来の縦・横・高さの比率を維持する。【高架・電車確定】
- 電車は高架中央の線路上を走る前提とする。【高架・電車確定】
- **編成数は固定しない。** 過去のA–B–Cの3両編成案はサイズ検討上の目安であり、本番仕様ではない。駅・ホームも3両に合わせることを前提にせず、編成数は実素材の縮尺・駅の長さ・街全体とのバランスを確認して決める。【高架・電車確定】
- 電車が高架と駅を走る背景演出を入れる計画。運行ルート、往復・周回方法、停車時間、編成数は未確定。
- 電車への乗車・変身、好きな位置で停止して降りる遊びは後回し。

### 8.4 未確定

1セルのゲーム内寸法、マップ全体の寸法、道路・歩道幅、高架高さ、建物寸法、歩行可能範囲と海際の停止方法の最終値は未確定。階段の形状・幅・デザイン、側壁や開口部の具体寸法も今回確定しない。高架幅3.0と電車のuniform scale 0.95は確定済み。8.2節の採用済み構成・砂浜の方向性・海の見せ方と、3.1節・9.4節の採用済み縮尺基準は維持する。過去のサイズ比較図は参考資料であり、厳密な現実寸法ではない。

### 8.5 縦高架の階段接続【確定方針・追加予定】

- 縦高架の海側手前に、将来地上道路へ降りる階段を設ける予定。
